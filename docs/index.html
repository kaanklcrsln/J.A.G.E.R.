A voice assistant that lives in your notch.

Say "Jager", ask for something, and it drops out of the notch, gets it done on your Mac and tells you about it. Then it goes back into the notch and pretends it was never there.

    How it works

    Jager itself is pretty dumb, on purpose. It has ears, a mouth and a nice little panel. The thinking happens in Claude Code, which Jager runs in the background with your request. Claude has a shell, AppleScript, your files and the ability to take a screenshot when it needs to look at something. You keep working while it does its thing. The notch shows you what it's up to.

    • Your voice stays on your Mac. Speech to text runs locally. Only the text of your request goes to Claude.
    • It remembers the conversation. "And is it charging?" after a battery question just works.
    • English or Turkish. English replies use a macOS voice, Turkish ones use EMA Lightning.
    • "Appreciated, Jager" sends it home.

    Install

    1. Install Claude Code and log in once. Jager borrows its brain.

      claude

    2. Give it ears.

      brew install whisper-cpp

    3. Download the dmg, drag Jager into Applications and open it. macOS will say it can't check the developer because I didn't pay Apple $99. Go to System Settings → Privacy & Security → Open Anyway. Once.

    4. Allow the microphone. Say "Jager, what time is it?" and enjoy your new butler.

    5. Optional: Turkish replies. Then pick Türkçe under Reply language in the Jager menu.

      git clone https://github.com/kaanklcrsln/J.A.G.E.R.
cd J.A.G.E.R. && npm run setup:turkish
    Read this bit. Jager runs Claude Code with full permissions, no confirmations. It can run commands, move and delete files and drive your apps. If it mishears you, it acts on what it heard. I'm fine with that on my own laptop. Decide for yourself, and turn off the wake word in the menu if you'd rather only use ⌥ Space.
